# API-Token
This repository shows an api created with node.js and express that connects to the Ethereum blockchain with the Token Tether USD contract. The api obtains information on the name of the token, the number of decimals, the symbol of the token, the balance of an account, as well as the assignment from one user to another, with the allowance function
To connect to the smart contract on the blockchain you must import your infura alchemy endpoint or another network you use.
You can replace the contract abi in the abi.json file with a contract abi that you want, you must remember to add the contract address in the .env file or wherever you want within the code.
